## פרופילים והתקדמות

לאתר יש פרופיל אחד לכל מי שמשחקת במכשיר. בכניסה הראשונה הוא שואל שם ואמוג'י,
וכל שמירה מתויגת אליו (`levygames.<profileId>.<namespace>`). ההתקדמות מוצגת
על כרטיסי המשחקים בדף הבית.

```
js/local-store.js   הדרייבר היחיד שנוגע ב-localStorage
js/profiles.js      רג'יסטרי הפרופילים
js/storage.js       ה-API שכל המשחקים עובדים מולו (אסינכרוני)
js/profile-gate.js  מסך "איך קוראים לך?" + המיגרציה מהשמירות הישנות
js/levygames-bridge.js  אותה שכבה, ל-<script> קלאסי ול-bundle של Vite
```

**אין DB ואין backend** — הכל ב-`localStorage` של הדפדפן. כלומר: אותה ילדה
בטאבלט ובלפטופ = שתי התקדמויות נפרדות, וניקוי היסטוריה מוחק הכל.

## הוספת משחק חדש

1. צרו תיקייה תחת `games/<id>/` עם `index.html` ו-`instructions.html`.
2. הוסיפו אובייקט אחד ל-`js/games-data.js`:

```js
{
  id: 'my-game',                  // חייב להיות זהה ל-gameId בדיווח ההתקדמות
  emoji: '🎯',
  name: 'שם המשחק',
  description: 'משפט אחד שמסביר מה עושים.',
  playUrl: 'games/my-game/index.html',
  instructionsUrl: 'games/my-game/instructions.html',
  playLabel: 'שחקי עכשיו!',       // אופציונלי
  tags: ['חד-שחקן', 'גילאי 6-10'], // אופציונלי
  gradient: ['#93C5FD', '#6EE7B7'],// אופציונלי - רקע פאנל האייקון
  progressUnit: 'תיקים',           // אופציונלי - ברירת מחדל 'שלבים'
  badge: 'חדש!',                   // אופציונלי
  video: 'assets/cards/x.mp4',     // אופציונלי - קליפ 2:1 במקום האמוג'י
  poster: 'assets/cards/x.webp',   // חובה אם יש video
}
```

3. ההב בונה את הכרטיס לבד.

### צ'קליסט לפני שמסיימים

- [ ] אפס קריאות ישירות ל-`localStorage` — הכל דרך `js/storage.js` או הגשר
- [ ] כל קריאות האחסון עם `await`
- [ ] `reportProgress()` נקרא באותו מקום שבו המשחק שומר, עם אותו `id`
- [ ] נתיבים יחסיים בלבד (`../../assets/...`), והאותיות הגדולות/קטנות מדויקות
- [ ] בלוק `<meta>`/Open Graph, `manifest` ו-`apple-touch-icon` הועתקו מדף קיים
- [ ] `?v=` הועלה בכל מקום שמייבא קובץ שנגעתם בו

**הפירוט המלא והמחייב: [`CLAUDE.md`](CLAUDE.md).**

## מבנה

```
index.html                 ההב
404.html                   דף שגיאה (מוגש אוטומטית; הנתיבים בו מוחלטים בכוונה)
manifest.webmanifest       הוספה למסך הבית
style.css                  עיצוב ההב
CLAUDE.md                  הנחיות הפיתוח המחייבות
assets/                    צלילי UI, אייקונים, תמונת שיתוף (og.png)
js/games-data.js           רשימת המשחקים - המקום היחיד שצריך לערוך
js/hub.js                  בונה את כרטיסי המשחקים (כולל ההתקדמות)
js/storage.js              שכבת האחסון - כל שמירה באתר עוברת דרכה
js/sfx.js                  שכבת נכסי הצליל (נתיבים מול import.meta.url)
games/<id>/                משחק עצמאי, כולל הנכסים הייחודיים שלו
src-games/<id>/            מקור של משחק שדורש build (Vite); התוצר נפרס ל-games/<id>/
```

### משחק עם build

שני משחקים הם פרויקטי Vite. `games/<id>/` שלהם הוא **תוצר build, לא מקור**:

| מקור | נפרס ל |
|---|---|
| `src-games/code-a-bot/` | `games/code-a-bot/` |
| `src-games/alfa-town/` | `games/alfa-town/` |

```bash
cd src-games/<id>
npm run build
rm -rf ../../games/<id>/assets     # שם הבנדל כולל hash - למחוק את הישן
cp -r dist/. ../../games/<id>/
```

`node_modules/` ו-`dist/` של תת-הפרויקט לא עולים לגיט; המקור והתוצר הנפרס כן.
פרטים ומלכודות: [`CLAUDE.md`](CLAUDE.md).

## Cache-busting

GitHub Pages מגיש עם `Cache-Control: max-age=600`, כך שמשתמשת שכבר ביקרה עלולה לקבל CSS/JS ישנים אחרי עדכון. לכן לכל קובץ CSS/JS מצורף `?v=N` - גם בתגיות `<link>`/`<script>` וגם בשורות ה-`import` בתוך המודולים.

**כשמשנים CSS או JS - מעלים את המספר בכל המקומות:**

```bash
grep -rn "?v=" --include=*.html --include=*.js .
```
